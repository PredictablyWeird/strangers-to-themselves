# A Causal Taxonomy of Failure Modes for Predicting LLM Benchmark Behavior from Abstract Questions

## 1. Setup and notation

The prediction pipeline has two branches joined at a shared latent variable.

A researcher with intent **I** (the construct they want to probe) formulates an abstract question **Q**. The model construes it as **C**, accesses self-information **K** about its latent disposition **D** (the actual policy-level tendency relevant to the benchmark), and emits answer **A**. The researcher applies a mapping **f** to produce prediction **P**.

Independently, the same disposition **D**, together with the benchmark context **X** (item wording, system prompt, harness, perceived situation) and sampling noise **ε**, generates realized behavior **b**, which the benchmark's scoring function **h** converts into an observed score **S**.

- **Elicitation branch:** I —(L1)→ Q —(L2)→ C —(L3)→ K —(L4)→ A —(L5)→ P
- **Behavior branch:** (D, X, ε) —(L6)→ b —(L7)→ S
- **Shared root:** D is the only variable feeding both branches — it is the source of K on the elicitation side and of b on the behavior side. The assumptions binding the two branches together (same D, same model, no interaction) are link L0.
- **Prediction failure:** P ≠ S.

A **prediction failure** is a mismatch between P and S beyond the tolerance the paper defines.

## 2. The completeness argument

P is a deterministic function of the path I → Q → C → K → A → P. S is generated by the path (D, X, ε) → b → S. The two paths share exactly one latent variable, D, and the framework's claim to validity rests on a set of root assumptions (L0) binding them together.

Therefore: **if P ≠ S, then at least one of the eight links L0–L7 failed to preserve the relevant information.** There is nowhere else for the error to enter — signal enters at D (and at I, for what the researcher wants to know about D), exits at P and S, and every transformation in between is enumerated. This makes the taxonomy exhaustive *at the level of links* by construction.

Two residual risks, which should be stated as limitations:

1. **The pipeline model itself could be wrong.** This risk is absorbed into L0: each modeling assumption of the pipeline is listed explicitly, and each assumption's violation is a failure mode. The residual is any *unstated* assumption — which is why an empirical residual bin (Section 6) remains necessary.
2. **Within-link mechanisms are open-ended.** The partition of failure *loci* is complete; the catalog of *mechanisms* realizing each locus (e.g., the specific ways RLHF produces a stale self-model) is illustrative and growing. The paper should claim the former, not the latter.

A note on the "ME" in MECE: the categories below are mutually exclusive as **defect types** (each names a break in a distinct arrow, derived from a distinct branch of a dichotomy tree). A single *observed* failure may instantiate several defects at once. The coding protocol should therefore be multi-label over a MECE code set — standard practice in root-cause analysis, and worth stating explicitly to preempt reviewer confusion.

## 3. The taxonomy

Each link is given with its MECE derivation (a dichotomy tree whose leaves are the failure modes), the failure modes, and boundary rulings where categories from informal brainstorming get split or relocated.

---

### L0 — Framework assumptions (root)

The pipeline presupposes three things. The MECE derivation is simply: *which stated presupposition fails?*

**F0.1 — No shared disposition (trait realism failure).** There is no common latent D that both the abstract answer and the benchmark behavior express. The "trait" (e.g., "honesty," "sycophancy") is a construct of the researcher, not a variable in the model: answers to abstract questions and behaviors on concrete items are generated by unrelated mechanisms. This is the deepest possible failure — every downstream link can be intact and prediction still fails, because there was nothing to predict *from*.

**F0.2 — Model or configuration drift.** The entity answering Q is not the entity taking B: different checkpoint, different system prompt regime, different inference-time configuration. The two branches sample different values of D.

**F0.3 — Measurement interaction.** Asking Q causally influences b — the branches are not independent. Within a shared context window this is in-context priming; across contexts it can arise if elicitation and evaluation data flow into further training. (Survey research documents the human analog as the *question–behavior effect* / mere-measurement effect, which is evidence this category is real rather than hypothetical.)

*Boundary ruling:* F0.1 vs. L6. If a common latent exists but its behavioral expression is moderated by context, that is L6. F0.1 is reserved for the case where the latent does not exist — abstract-answer variance and behavior variance don't load on a shared factor. The two are empirically distinguishable in principle (factor structure across many probes and items), which is a reason to keep them separate.

---

### L1 — Intent → Question (researcher formulates Q)

*MECE derivation:* compare the set of constructs/situations Q picks out with the intended construct. Either Q's denotation properly contains the target among others (imprecise), or it is precise but picks out the wrong thing, or it matches (no failure).

**F1.1 — Underspecification.** Q is compatible with multiple constructs or situation classes; the answer cannot pin down the one the benchmark instantiates. *(Original list item 1.)*

**F1.2 — Mis-specification.** Q is precise but operationalizes the wrong construct — a sharp question about a neighboring disposition. (E.g., asking about willingness to *state* a controversial fact when the benchmark measures willingness to *act* on it.)

---

### L2 — Question → Construal (model interprets Q)

*MECE derivation:* given Q's intended meaning, the model's construal C is either systematically wrong, or unstable under meaning-preserving transformations, or correct (no failure).

**F2.1 — Stable misconstrual.** The model resolves Q's meaning differently than intended, consistently. With F1.1 this is the joint mechanism behind "the model answered a different question."

**F2.2 — Framing instability.** C (and hence A) varies with semantically irrelevant surface features — wording, option order, persona cues. *(Original list item 2.)* Instability is a distinct defect from being wrong: a stably misconstrued question can be fixed by rewording; an unstable one has no single "correct framing" to find, and the honest prediction target becomes a distribution over framings.

*Boundary ruling:* framing effects that operate on *how the answer is produced* rather than on construal (e.g., acquiescence to a leading question the model construed correctly) belong at F4.3. The test: does the variation enter before or after the disposition is queried?

---

### L3 — Construal → Accessed self-knowledge (introspection)

*MECE derivation:* Does any information channel from the current policy D to the answer exist? If no → F3.1. If yes: is the channel's source the current policy itself? If no → source is other entities (F3.2) or a past self (F3.3). If yes: is the retrieved information faithful? If no → F3.4. If yes: is the summary judgment computed from it correct? If no → F3.5.

**F3.1 — No access.** No mechanism connects the query to D at all. The observable symptom is *confabulation*: the model answers anyway, fluently, from plausibility rather than access. *(Original list item 3, first half.)*

**F3.2 — Wrong source (secondhand self-model).** Access exists, but to a self-model built from third-person data: training-corpus descriptions of "AI assistants" in general, of other models, or of the assistant *persona*. The report is sincere and may even be internally consistent — it just describes a different object than the policy that will sit the benchmark. *(Original list item 3, refined.)*

**F3.3 — Stale source.** The self-model describes an earlier version of the policy — typically pretraining-derived self-knowledge that post-training (RLHF, safety training) has since falsified behaviorally without updating descriptively.

**F3.4 — Noisy access.** A genuine but low-fidelity channel: the model retrieves something about its dispositions, degraded.

**F3.5 — Judgment error (integration failure).** The evidence accessed is adequate but the summary judgment computed from it is wrong — miscalibrated self-assessment despite intact retrieval (the machine analog of Dunning–Kruger-style misestimation, or availability-driven overweighting of salient episodes). *This category was added by the adjacent-field cross-check (Section 5): Tourangeau's survey-response model has a distinct "judgment" stage between retrieval and response, and the original draft taxonomy had no counterpart.*

*Boundary ruling (persona divergence):* the case where the assistant character sincerely reports the *character's* dispositions while the underlying policy diverges is classified here, under F3.2 (wrong source: the persona), not under L4 dishonesty. Reason: the sincere/insincere dichotomy at L4 is well-defined only relative to what was accessed; in persona cases the report faithfully conveys what was accessed — the defect is *which self-model got queried*. This ruling should be stated in the paper, because informal usage ("the model is lying about itself") conflates the two, and they have different fixes (better elicitation of the policy vs. honesty interventions).

---

### L4 — Accessed content → Answer (report generation)

*MECE derivation:* Is the report attempting to convey the accessed content? If **yes**, where is information lost: in expressibility (F4.1), in the imposed response format (F4.2), or in a systematic trained shift (F4.3)? If **no**: is content withheld (F4.4) or replaced (F4.5)?

Sincere distortions:

**F4.1 — Verbalization bottleneck.** The disposition is accessed in some non-propositional form but cannot be rendered in words — implicit knowledge the policy acts on but cannot report.

**F4.2 — Format loss.** The true answer is conditional ("it depends on X") and the forced format — yes/no, Likert, single token — destroys exactly the conditional structure that carries the predictive information.

**F4.3 — Response bias.** Sycophancy, social desirability, acquiescence, extremity bias: trained-in shifts of the report toward what sounds good or what the asker seems to want, without deceptive intent in any strong sense.

Insincere reports:

**F4.4 — Refusal.** The model declines to report what it accessed. *(Original list item 4, first half.)*

**F4.5 — Misreport.** The model states something other than what it accessed — lying, as distinct from declining. *(Original list item 4, second half.)* Worth separating because refusal is observable (you know you got nothing) while misreport is not (you think you got something), so they damage the prediction differently: refusal costs coverage, misreport costs validity.

---

### L5 — Answer → Prediction (researcher inference)

*MECE derivation:* P = f(A). Any such inference has exactly four components — what A means, what A covers, how to aggregate it, and how confident it is — so its failures partition into:

**F5.1 — Semantic misreading.** The researcher misinterprets what A asserts, including flattening hedges and conditionals the model did express.

**F5.2 — Scope / reference-class mismatch.** A is a faithful report about one distribution of situations; the benchmark samples another (typical cases vs. adversarial tail cases). *Note how the pipeline disambiguates this famously fuzzy category into three precise ones:* if Q failed to specify the distribution → F1.1; if Q specified it and the model construed otherwise → F2.1; if A is faithful about distribution D_A and the researcher applies it to benchmark distribution D_B ≠ D_A → F5.2.

**F5.3 — Aggregation error.** Wrong functional form from dispositional report to score prediction: treating a propensity as a per-item probability, ignoring item-difficulty spread, ignoring that benchmark scores are bounded and discretized.

**F5.4 — Uncertainty mishandling.** Treating a hedged or distributional answer as a point estimate; miscalibrated conversion of the model's expressed confidence into prediction confidence.

---

### L6 — Disposition → Behavior (generation)

*MECE derivation:* b = g(D, X, ε) plus other stable properties of the model. Divergence between D-implied behavior and actual behavior therefore comes from exactly three sources beyond D: the context X, other stable determinants, or the noise ε.

**F6.1 — Contextual override.** Features of the concrete item — jailbreak wrapper, few-shot examples, system prompt, role-play frame, length pressure — dominate the disposition. The classic attitude–behavior gap: strong situations swamp traits.

**F6.2 — Evaluation-awareness effects.** A named subcase of contextual override, separated for its importance to this literature: the model detects (or fails to detect) that it is being evaluated, and behaves under a different regime than the one the abstract question probed. Includes deliberate sandbagging on the benchmark — deceptive *behavior* rather than deceptive *report*, which is why it lives here and not at F4.5.

**F6.3 — Non-target stable determinants.** Behavior is jointly produced by D and other stable properties the abstract question did not probe: capability gates propensity ("would, but can't" / "can, but won't" — asking about one while the benchmark requires both), and memorization/contamination injects behavior that no disposition-level report could predict.

**F6.4 — Intrinsic stochasticity.** Behavior is sampled; D fixes at most a distribution. Even a perfect self-report predicts only probabilities, leaving an irreducible aleatoric floor on single-run prediction accuracy.

*Boundary rulings:* (a) Contamination is placed here, not at L7 — memorized answering is *real behavior* generated by a non-target determinant, not a scoring error. (b) "Representational mismatch" (the abstract query and the concrete task engage different machinery) splits across F0.1 (no shared latent at all) and F6.1/F6.3 (shared latent, expression moderated) — which one applies is an empirical question per construct, not a definitional one.

---

### L7 — Behavior → Score (measurement)

*MECE derivation:* S = h(b), where h comprises a scoring rule applied to a finite sample under a fixed operationalization. Failures: the rule is systematically wrong (F7.1), the sample is finite (F7.2), or the operationalization is underdetermined by the prediction statement (F7.3).

**F7.1 — Harness artifacts.** Parsing, answer extraction, formatting requirements, judge-model errors: the score misrepresents the behavior that actually occurred.

**F7.2 — Sampling error.** Finite item sets and single generations per item make S a noisy estimate of the behavioral tendency; the prediction may be right about the tendency and wrong about the realization.

**F7.3 — Operationalization ambiguity.** "The model's benchmark behavior" is underdefined: temperature, template, k-shot count, scoring threshold all shift S, and the prediction P did not fix which operationalization it referred to. The prediction and the measurement answer subtly different questions.

---

## 4. Where the original four failure modes land

| Original item | Taxonomy code(s) | What the derivation added |
|---|---|---|
| "Impossible — prompt isn't specific enough" | F1.1 | Split from F1.2 (precise but wrong) and F2.1 (model resolves ambiguity differently) |
| "Sensitive to framing, framing isn't optimal" | F2.2 (+ F4.3) | Split construal instability from response bias; "no optimal framing exists" reframed as distributional prediction target |
| "The model doesn't know" | F3.1–F3.5 | Split into no-access, wrong-source, stale-source, noisy-access, judgment error — different mechanisms, different remedies |
| "Knows but doesn't want to say" | F4.4, F4.5 (persona cases → F3.2) | Split refusal (costs coverage, observable) from misreport (costs validity, unobservable); persona divergence relocated to access |

Everything in L0, L5, L6, and L7 — fourteen of the twenty-eight categories — was absent from the original list, confirming the earlier diagnosis: informal brainstorming clustered on the elicitation branch and left the shared-latent assumptions, the researcher's own inference step, and the entire behavior branch uncovered.

## 5. Cross-check against adjacent-field taxonomies

Method: for each adjacent field with a mature failure/threat taxonomy, map their categories onto ours and ours onto theirs. A category of theirs with no counterpart here is a candidate gap; a category of ours with no counterpart there is either LLM-specific (fine, if arguable) or suspect.

### 5.1 Survey methodology — Tourangeau, Rips & Rasinski's four-stage response model

Their stages: comprehension → retrieval → judgment → response (with response editing).

| Their stage / bias | Our code |
|---|---|
| Comprehension failure | L2 (F2.1, F2.2) |
| Retrieval failure | L3 (F3.1, F3.4) |
| **Judgment/estimation error** | **F3.5 — was missing; added by this check** |
| Response mapping (format effects) | F4.2 |
| Response editing (social desirability) | F4.3, F4.4 |
| Acquiescence, order effects | F2.2, F4.3 |
| Question–behavior / mere-measurement effect | F0.3 — independently confirms a category that was speculative |

**Outcome: one genuine addition (F3.5) and one confirmation (F0.3).** The reverse diff also passes: our L3 source distinctions (F3.2, F3.3) have no survey counterpart because human respondents cannot have learned their self-model primarily from third-person descriptions of *other* respondents — the categories are LLM-specific for an articulable reason, which is the acceptable kind of asymmetry.

### 5.2 Construct validity / threats-to-validity (Cronbach & Meehl; Messick; Shadish, Cook & Campbell)

| Their category | Our code |
|---|---|
| Construct underrepresentation | F1.1 |
| Construct-irrelevant variance | F2.2, F4.3, F6.3, F7.1 |
| Mono-operation / mono-method bias | F7.3 (and the single-question analog at L1) |
| Reliability / statistical conclusion validity | F6.4, F7.2, F5.3, F5.4 |
| External validity / generalization | F5.2, F6.1 |
| Reactivity to the experimental situation | F0.3, F6.2 |

**Outcome: full coverage both directions; no additions.** Their framework maps cleanly because it is itself organized causally.

### 5.3 Attitude–behavior research (LaPiere; Ajzen & Fishbein; Mischel; Fazio)

| Their finding/principle | Our code |
|---|---|
| Attitude–behavior gap (LaPiere) | L6 generally |
| Correspondence/compatibility principle — attitude and behavior measures must match in Target, Action, Context, Time | F1.1, F5.2 (TACT is essentially a checklist for avoiding both) |
| Situational strength (Mischel) | F6.1 |
| Behavior = intention × perceived control (theory of planned behavior) | F6.3 (capability gating) |
| Deliberative vs. spontaneous processing (Fazio's MODE) | F6.1 — same disposition, different access route under time/format pressure |

**Outcome: full coverage; no additions.** The TACT principle is worth citing in the paper as prior art for F5.2 — it is the same insight, seventy years earlier.

### 5.4 Introspection literature (Nisbett & Wilson; Schwitzgebel; Carruthers)

| Their finding | Our code |
|---|---|
| Confabulation of reasons (Nisbett & Wilson) | F3.1 |
| General unreliability of introspection (Schwitzgebel) | F3.4 |
| Introspection as third-person self-interpretation (Carruthers) | F3.2 — their theory arguably predicts our category |

**Outcome: full coverage; no additions.** Carruthers' interpretive-sensory-access theory is a useful citation: it argues even *human* self-knowledge is partly secondhand, which positions F3.2 as a difference of degree, not kind.

### 5.5 Cross-check summary

Four fields, one genuine gap found (F3.5), one speculative category independently confirmed (F0.3), zero categories of theirs left unmapped, and every unmatched category of ours defensible as LLM-specific. This is the pattern the completeness argument predicts if the causal derivation is doing its job: adjacent fields contribute refinements within links, not new links.

## 6. Using the taxonomy: coding protocol and honest limits

**Multi-label coding.** Code each observed prediction failure with all applicable defect codes, not a single primary cause. Mutual exclusivity holds at the level of defect definitions; real failures are frequently multi-causal (an underspecified question *and* a sycophantic answer *and* a noisy benchmark).

**Residual bin.** Include an explicit "L?/other" code. Its empirical rate is the measured incompleteness of the taxonomy and should be reported as a headline number, not buried. A nonzero rate is expected (unstated L0 assumptions); a growing rate signals a missing link.

**Distinguishability ≠ completeness.** Several categories are observationally identical from the outside: F3.1 (confabulation), F3.2 (secondhand self-model), and F4.5 (misreport) can produce the same transcript. The taxonomy partitions *causes*; assigning a cause to an instance requires extra instruments — consistency checks across framings (separates F2.2 from stable defects), calibration analysis (F3.5), probing or interpretability access (F3.1 vs. F4.5), behavioral honesty tests (F4.4/F4.5). The paper should state which distinctions its experimental design can and cannot make, and code indistinguishable cases at the finest level the evidence supports (e.g., "L3/L4-insincere, unresolved").

**Claim strength.** Defensible claim: *exhaustive partition of failure loci at the link level, derived from the causal structure of the prediction task, validated against four adjacent literatures.* Not defensible: exhaustiveness of mechanisms within links. Say the first, disclaim the second.
